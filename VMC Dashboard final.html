Google Sheet Sync

How this works. Every checklist reads straight from its own Google Sheet — the tab whose name matches the checklist (other tabs in the file are ignored). Columns are matched by their header text on every sync, so if you add a question column or delete one in the sheet, the dashboard picks it up on the next refresh with nothing to change here.
